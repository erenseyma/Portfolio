JWT - JSON Web Token

Güvenli kimlik doğrulama için token tabanlı çözüm

JWT (JSON Web Token), web uygulamalarında kullanıcı kimlik doğrulaması ve oturum yönetimi için kullanılan hafif, güvenli ve yaygın olarak benimsenmiş bir token standardıdır.

JWT Nedir?

JWT, kullanıcı giriş yaptıktan sonra sunucu tarafından oluşturulan ve istemciye verilen bir erişim jetonudur. Kullanıcı bu token'ı sonraki isteklerde kim olduğunu kanıtlamak için gönderir. Stateless (durumsuz) çalışma prensibi sayesinde sunucu tarafında oturum bilgisi tutulmasına gerek kalmaz.

JWT Yapısı

JWT token'ı üç ana bölümden oluşur ve noktalarla ayrılır:

Header

Token'ın türü ve kullanılan imzalama algoritmasını içerir

{ "alg": "HS256", "typ": "JWT" }

Payload

Kullanıcıya ait bilgiler ve claim'leri içerir

{ "id": 5, "email": "seyma@example.com", "role": "admin", "exp": 1635724800 }

Signature

Header ve Payload'ın gizli anahtarla imzalanmış hali

HMACSHA256( base64UrlEncode(header) + "." + base64UrlEncode(payload), secret-key )

Çalışma Mantığı

1
Kullanıcı Girişi: Kullanıcı kimlik bilgilerini gönderir
2
Token Üretimi: Sunucu kimlik doğrulama başarılıysa JWT oluşturur
3
Token Saklama: İstemci token'ı localStorage veya sessionStorage'da saklar
4
İstek Gönderme: Sonraki isteklerde Authorization header'ı ile token gönderilir
5
Token Doğrulama: Sunucu token'ı çözerek imzayı kontrol eder ve kullanıcıyı doğrular

Avantajları

Stateless

Sunucu tarafında oturum bilgisi tutulmaz, performans avantajı sağlar

Güvenli

İmza mekanizması sayesinde token değiştirilemez

Esnek

Farklı platformlar ve diller arasında kolayca kullanılabilir

Scalable

Mikroservis mimarilerinde ideal çözüm sunar

Standardize

RFC 7519 standardı ile endüstri çapında kabul görmüştür

Kendi Kendine Yeten

Token içinde kullanıcı bilgileri taşır, veritabanı sorgusuna gerek kalmaz

Güvenlik Önlemleri

  • Gizli Anahtar: Güçlü ve güvenli bir secret key kullanın
  • Token Süresi: Kısa süreli access token'lar ve uzun süreli refresh token'lar kullanın
  • HTTPS: Token'ları her zaman HTTPS üzerinden iletin
  • Storage: Token'ları güvenli şekilde saklayın (httpOnly cookies önerilir)
  • Claim Doğrulama: Token içindeki tüm claim'leri doğrulayın

Gerçek Kullanım Senaryosu

React + ASP.NET Core Uygulaması:

  • Kullanıcı React arayüzünden giriş yapar
  • ASP.NET Core API, kimlik doğrulama başarılıysa JWT üretir
  • React, token'ı localStorage'da saklar
  • Her API isteğinde token Authorization header'ı ile gönderilir
  • ASP.NET Core, gelen token'ı doğrular ve kullanıcıyı tanır

Sonuç

JWT, modern web ve mobil uygulamalarda güvenli kimlik doğrulama sağlamak için etkili ve standart bir yöntemdir. Sunucu yükünü azaltır, mikroservis yapılarında kolayca uygulanabilir ve kullanıcı oturumlarını sade bir biçimde yönetir.

Doğru güvenlik önlemleri alındığında, JWT hem geliştiriciler hem de kullanıcılar için güvenli ve performanslı bir kimlik doğrulama deneyimi sunar.
