.NET Generic Yapılar

Tek kodla her türde çalışan tip güvenlikli yapı

Generic yapılar, .NET platformunda tip güvenliğini sağlarken kod tekrarını azaltan ve esnek yapılar oluşturmamızı sağlayan güçlü bir programlama tekniğidir.

Generic Yapı Nedir?

Generic, .NET'te tip parametreleri kullanarak veri tipinden bağımsız programlama yapılmasını sağlar.

Generic Yapının Temel Çalışma Prensibi

Generic Sınıflar

Generic sınıflar, tip parametresi alarak tanımlanır.

Generic Yapının Pratik Kullanımı

Generic Constraints

Generic yapılarda tip parametreleri için kısıtlamalar belirlenebilir:

Kısıtlama Açıklama
where T : class Yalnızca referans tipler
where T : struct Yalnızca değer tipler
where T : new() Parametresiz yapıcı zorunlu
where T : BaseClass Belirli sınıftan türetilmiş
where T : IInterface Belirli interface uygulamalı

Bakım Kolaylığı

IntelliSense Desteği

Daha iyi kod tamamlama sunar

Ne Zaman Kullanılır?

  • Repository Pattern - Tüm entity'ler için ortak CRUD işlemleri
  • Utility Sınıfları - Farklı tiplerle çalışan yardımcı metodlar
  • Collection İşlemleri - Tip güvenli koleksiyon yönetimi
  • Servis Katmanı - Benzer iş mantığına sahip servisler

Önemli Noktalar

  • Generic yapılar runtime'da JIT tarafından spesifik tiplere dönüştürülür
  • Performans avantajı için boxing/unboxing'i önler
  • Tip güvenliği sayesinde runtime hataları azalır
  • Kod tekrarını önleyerek bakımı kolaylaştırır

Sonuç

Generic yapılar, .NET platformunda tekrar kullanılabilir, bakımı kolay ve tür güvenliği yüksek kod geliştirme imkânı sağlar.

Generic Repository yapısı, modern .NET projelerinde yaygın olarak tercih edilmektedir ve doğru uygulandığında geliştirme sürecini önemli ölçüde hızlandırır.
