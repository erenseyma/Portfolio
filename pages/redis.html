Redis

Yüksek performanslı bellek tabanlı veri deposu

Redis (Remote Dictionary Server), verileri bellek (RAM) üzerinde saklayan, açık kaynaklı ve yüksek performanslı bir veri yapısı deposudur. Genellikle cache (önbellekleme), oturum yönetimi, mesaj kuyruğu ve gerçek zamanlı veri işlemleri için kullanılır.

Redis Nedir?

Redis, NoSQL veritabanı kategorisinde yer alan ve verileri anahtar-değer (key-value) çiftleri şeklinde saklayan bir veri deposudur. Geleneksel veritabanlarından farklı olarak verileri disk yerine RAM'de tutarak mikro saniyeler seviyesinde okuma/yazma performansı sağlar.

Veri Yapıları

Redis sadece metin değil, birçok farklı veri yapısını destekler:

String

Basit anahtar-değer çiftleri

SET username "seyma"
GET username

List

Sıralı veri listeleri

LPUSH users "ali"
RPUSH users "veli"
LRANGE users 0 -1

Set

Benzersiz değerlerden oluşan koleksiyonlar

SADD tags "redis"
SADD tags "database"
SMEMBERS tags

Hash

Nesne benzeri veriler

HSET user:1 name "Şeyma"
HSET user:1 age 25
HGETALL user:1

Kullanım Alanları

🚀 Cache (Önbellek)

Sık kullanılan verileri RAM'de tutarak uygulama performansını artırır. Veritabanı sorgularını azaltır.

👤 Session Yönetimi

Kullanıcı oturum bilgilerini hızlıca erişilebilir hale getirir. JWT token'ları saklamak için idealdir.

📨 Message Queue

Arka plan görevlerini veya mesaj kuyruğunu yönetir. Pub/Sub pattern ile çalışır.

⚡ Gerçek Zamanlı Uygulamalar

Sohbet uygulamaları, skor tabloları, canlı bildirim sistemleri gibi anlık veri gerektiren sistemler.

Performans Karşılaştırması

Redis vs Geleneksel Veritabanları

  • Redis: Veriler RAM'de → Mikro saniye seviyesinde yanıt
  • SQL Veritabanları: Veriler diskte → Milisaniye seviyesinde yanıt
  • Okuma Hızı: Redis, disk tabanlı veritabanlarından 100-1000 kat daha hızlı
  • Yazma Hızı: Redis, saniyede yüzbinlerce işlem yapabilir

ASP.NET Core ile Redis Kullanımı

// Startup.cs'de Redis servisini ekleme services.AddStackExchangeRedisCache(options => { options.Configuration = "localhost:6379"; options.InstanceName = "SampleInstance"; }); // Controller'da kullanım public class UserController : Controller { private readonly IDistributedCache _cache; public UserController(IDistributedCache cache) { _cache = cache; } [HttpGet("{id}")] public async Task GetUser(int id) { var cacheKey = $"user_{id}"; var cachedUser = await _cache.GetStringAsync(cacheKey); if (!string.IsNullOrEmpty(cachedUser)) { return Ok(JsonSerializer.Deserialize(cachedUser)); } // Veritabanından getir var user = await _userService.GetUserById(id); // Redis'e kaydet (5 dakika cache'le) await _cache.SetStringAsync(cacheKey, JsonSerializer.Serialize(user), new DistributedCacheEntryOptions { AbsoluteExpirationRelativeToNow = TimeSpan.FromMinutes(5) }); return Ok(user); } }

Avantajları

Yüksek Performans

Veriler bellekte tutulduğu için çok hızlı erişim sağlar

Esnek Veri Yapıları

String, List, Set, Hash gibi farklı veri türlerini destekler

Kolay Ölçeklenebilirlik

Redis Cluster ile yatay ölçeklendirme yapılabilir

Kalıcı Depolama

İstenirse veriler diske yazılabilir (RDB, AOF)

Atomic İşlemler

Tüm komutlar atomik olarak çalışır, veri tutarlılığı sağlar

Yaygın Destek

Tüm popüler programlama dilleri için client kütüphaneleri mevcut

Gerçek Hayat Senaryosu

E-ticaret Uygulaması:

  • Sepet İşlemleri: Kullanıcı sepetini Redis Hash'lerde saklama
  • Ürün Cache: Sık görüntülenen ürün bilgilerini cache'leme
  • Session: Kullanıcı oturumlarını Redis'te tutma
  • Öneri Sistemi: Benzer ürün önerilerini Redis Set'lerde saklama
  • Sıralama: En çok satan ürünleri Redis Sorted Set ile yönetme

Sonuç

Redis, modern uygulamalarda performans artırmak ve anlık veri yönetimi sağlamak için güçlü bir çözümdür. Özellikle mikroservis yapılarında, JWT ile kimlik doğrulama, kullanıcı oturumu tutma veya cache mekanizması kurarken yaygın olarak tercih edilir.

Doğru kullanıldığında, Redis uygulamalarınızın performansını önemli ölçüde artırabilir ve kullanıcı deneyimini iyileştirebilir.
